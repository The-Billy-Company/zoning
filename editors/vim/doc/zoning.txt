*zoning.txt*                    Zoning architecture contracts

Install this directory on 'runtimepath'. Files ending in .zone receive the
zoning filetype, syntax, indentation, folding, and language-server support.

BIND uses the same extension, so a file is claimed only when its first
declaration is `package` or `workspace`, which is how the tool itself tells a
contract from a nameserver file. Everything else keeps whatever filetype the
editor's own content detection gives it.

The executable is never bundled. Set this before the plugin loads if `zoning`
is not on PATH:
>
  let g:zoning_executable = '/absolute/path/to/zoning'
<
Neovim 0.11 uses its native |vim.lsp.enable()| configuration. Vim detects
vim-lsp, vim-lsc, ALE, and coc.nvim when they are already installed.

Terminal icons do not use SVG. |zoning#icon()| returns `≡` by default:
>
  let g:zoning_nerd_font = 1       " 󰙅
  let g:zoning_ascii_icon = 1      " [=]
<
